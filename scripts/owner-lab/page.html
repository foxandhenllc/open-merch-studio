OPEN MERCH STUDIO / LOCAL OWNER REHEARSAL

Make the store yours. Then run a small merch drop.

This installation saves your changes in a local database and private files. AI images, payments, provider connections and hosting are simulated. It cannot charge a card, place a production order or send email. Use sample customer details and artwork here.

Open store admin →Visit collections →Open the workbench →

Start as a store owner

  1. Use the access code in artifacts/private/owner-lab/ACCESS.md to open admin.
  2. In Installation, choose a persona. Follow the tasks and save your progress.
  3. In Store profile, change the brand, contact details and policies. Upload an example image, prepare a logo/share image, save and review, then publish. Choose Connections → Redeploy with saved values. The lab rebuilds locally; wait for it to return and refresh.
  4. Create a collection, attach artwork, review products and prices, publish, then review the print layouts and enable simulated ordering.
  5. Visit the collection as a customer. Review the saved print, complete simulated checkout, then inspect the order in admin.

Connection forms accept only dummy values starting with lab-. Do not enter real account keys. Production-hosting wording inside admin describes the real deployment workflow; in this rehearsal it only changes local files.

Resume and recover

A backup pauses this local store briefly and pairs the database with its private files. Restore creates a separate copy and switches this lab to it; the previous database and files remain intact. This proves local recovery, not cloud disaster recovery.
